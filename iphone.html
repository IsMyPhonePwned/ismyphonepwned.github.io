How to get a sysdiagnose

Trigger a sysdiagnose on the iPhone, then pull it over USB here or upload a .tar.gz you already have.

Trigger on the iPhone

  1. Press and release Volume Up, Volume Down, and the Side button together (~0.7s). Holding too long locks the device.
  2. Wait about 5 minutes for collection to finish (many models vibrate when done).

Pull via USB (this page)

  1. Use Chrome or Edge on desktop (not Safari/Firefox). Unlock the iPhone.
  2. Connect USB, Request iPhone, then pair (accept Trust) or load a pair-record plist.
  3. Refresh archives, select a .tar.gz, and analyze in the browser.

On Linux, stop usbmuxd if it already claimed the USB device. Pairing stays in this tab only.

Or upload a file

Use Upload File with an existing sysdiagnose_*.tar.gz.
