        Help
        
        
      
        
      
        
        
        
          
        Privacy
        
          
        Nothing is sent to the cloud. Your APKs, APKM split packages, DEX files, and analysis stay local on this machine — parsing, decompiling, and scans all run in your browser (WASM).
        
          
        Notes, renames, and scan results are stored only in this browser’s localStorage (or in files you export yourself).
        
        
        
        
        
          
        Security scans
        
          
        Scan runs three local engines from dex-decompiler: vulnerability detectors (IPC, PendingIntent/PITracker, ZipSlip, Custom Tabs, nested Intent redirect, broadcasts, WebView, SSL, crypto, storage, trackers, …), Semgrep-style rules (starter + OWASP MASTG), and Mariana Trench–style taint solving (including field/extra breadcrumbs on traces).
        
        
        
        
        
          
        Compare (DEX)
        
          
        With an APK or DEX already open, click Compare with… in the header (or Choose other APK… on the Compare tab) and pick the other build. Side A is the file you already loaded; only Dalvik bytecode is matched. Identical classes are omitted. Click a changed method for a line-aligned source diff — nothing is sent to the cloud.
        
        
        
        
        
          
        Patch / Repack
        
          
        The Patch tab runs apk-patch in WASM. The Device tab uses WebUSB ADB (webadb-rs) to list apps, inject/attach arm_goauld, and speak the goauld protocol over localabstract:goauld-agent-<pid>. Host aapt2 is unavailable in-browser. APKM/XAPK base APK only for Patch rebuild.
